## 1. Tổng quan

vnbroker không sử dụng database truyền thống. Dữ liệu được lưu trữ trong:

- **SQLite:** Health store (trạng thái sức khoẻ provider)
- **In-memory:** Cache (TTL), module counters
- **DataFrame:** Dữ liệu thị trường (OHLCV, price board, etc.)

## 2. Health Store Schema

**File:** `vnbroker/core/health_store.py`

```sql
CREATE TABLE health_state (
    module_source TEXT PRIMARY KEY,  -- "quote:vci", "quote:kbs"
    failures INTEGER DEFAULT 0,
    cooldown_until_wall REAL,
    last_success_wall REAL,
    last_failure_wall REAL
);
```

## 3. DataFrame Schemas

### 3.1 OHLCV (History)

| Column | Type | Mô tả |
|:--|:--|:--|
| `time` | datetime64[ns, Asia/Ho_Chi_Minh] | Thời gian (tz-aware) |
| `open` | float64 | Giá mở cửa |
| `high` | float64 | Giá cao nhất |
| `low` | float64 | Giá thấp nhất |
| `close` | float64 | Giá đóng cửa |
| `volume` | int64 | Khối lượng |

### 3.2 Price Board

| Column | Type | Mô tả |
|:--|:--|:--|
| `symbol` | str | Mã chứng khoán |
| `time` | datetime64 | Thời gian |
| `exchange` | str | Sàn giao dịch |
| `ceiling_price` | float64 | Giá trần |
| `floor_price` | float64 | Giá sàn |
| `reference_price` | float64 | Giá tham chiếu |
| `close_price` | float64 | Giá khớp |
| `volume_accumulated` | int64 | Khối lượng lũy kế |

### 3.3 Company Profile

| Column | Type | Mô tả |
|:--|:--|:--|
| `symbol` | str | Mã chứng khoán |
| `company_name` | str | Tên công ty |
| `exchange` | str | Sàn giao dịch |
| `industry` | str | Ngành |
| `listing_volume` | int64 | Khối lượng niêm yết |
