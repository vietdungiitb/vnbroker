## A. Kiến trúc hai tầng (Two-Tier Architecture)

| Thuật ngữ | Tiếng Anh | Định nghĩa |
|:--|:--|:--|
| **Tầng 1** | Tier 1 | Dữ liệu thị trường ẩn danh, người dùng không cần biết provider. Gồm VCI, KBS (no-auth) + DNSE, SSI, TCBS (cần auth). |
| **Tầng 2** | Tier 2 | Dữ liệu cá nhân hóa, bắt buộc chọn provider tường minh. Gồm TCBS iFlash OpenAPI, SSI FastConnect. |
| **Provider** | Provider | Nguồn dữ liệu thị trường (VCI, KBS, TCBS, DNSE, SSI). |
| **Adapter** | Adapter | Lớp trung gian giữa API và provider, chuẩn hoá schema. |
| **Failover** | Failover | Cơ chế tự động chuyển sang provider khác khi provider hiện tại lỗi. |
| **Health Store** | Health Store | Cơ sở dữ liệu trạng thái sức khoẻ provider (SQLite + in-memory). |
| **Circuit Breaker** | Circuit Breaker | Cơ chế ngắt kết nối khi provider liên tục lỗi, tránh quá tải. |

## B. Dữ liệu thị trường

| Thuật ngữ | Tiếng Anh | Định nghĩa |
|:--|:--|:--|
| **OHLCV** | OHLCV | Open, High, Low, Close, Volume — dữ liệu nến cơ bản. |
| **History** | Historical Data | Dữ liệu giá lịch sử theo ngày/tuần/tháng. |
| **Intraday** | Intraday Data | Dữ liệu giá trong ngày (tick hoặc 1m/5m/15m/30m). |
| **Price Board** | Price Board | Bảng giá realtime hai chiều (bid/ask). |
| **Price Depth** | Price Depth | Độ sâu sổ lệnh (order book depth). |
| **Match Type** | Match Type | Loại khớp lệnh: `Buy`, `Sell`, `Unknown`. |
| **Price Unit** | Price Unit | Đơn vị giá: `VND` (đồng) hoặc `THOUSAND_VND` (nghìn đồng). |

## C. Kỹ thuật

| Thuật ngữ | Tiếng Anh | Định nghĩa |
|:--|:--|:--|
| **Connection Pool** | Connection Pool | Nhóm kết nối HTTP dùng chung, tái sử dụng TCP connection. |
| **Thread Pool** | Thread Pool | Nhóm thread dùng chung cho thao tác đồng thời. |
| **Bulk Router** | Bulk Router | Bộ định tuyến chia tải bulk trên nhiều provider. |
| **Normalizer** | Normalizer | Lớp chuẩn hoá dữ liệu đầu ra (tz, boundary, sort). |
| **Provider Pool** | Provider Pool | Nhóm provider khả dụng, bao gồm auth providers. |
| **Health Router** | Health Router | Bộ định tuyến dựa trên sức khoẻ provider. |
| **Adaptive Controller** | Adaptive Controller | Bộ điều chỉnh concurrency động theo tỉ lệ lỗi. |
| **Global Pressure** | Global Pressure | Áp lực chung giữa các provider, giảm concurrency khi có stress. |

## D. Phát triển

| Thuật ngữ | Tiếng Anh | Định nghĩa |
|:--|:--|:--|
| **WP** | Work Package | Gói công việc trong multi-agent workflow. |
| **Gate** | Gate | Cổng kiểm tra bắt buộc trong quy trình SDLC. |
| **ADR** | Architecture Decision Record | Hồ sơ quyết định kiến trúc. |
| **SDLC** | Software Development Life Cycle | Vòng đời phát triển phần mềm. |
| **TDD** | Test-Driven Development | Phát triển hướng test: viết test trước, code sau. |
