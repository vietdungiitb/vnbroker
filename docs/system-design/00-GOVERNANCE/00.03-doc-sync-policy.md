# 00.03 — Chính sách đồng bộ tài liệu ↔ code base

| | |
|:--|:--|
| **Mã tài liệu** | `SD-GOV-03` |
| **Phiên bản** | 1.0 |
| **Ngày ban hành** | 2026-10-08 |

---

## 1. Nguyên tắc

1. **Tài liệu là nguồn sự thật:** Khi code và tài liệu lệch nhau, tài liệu phải được cập nhật TRƯỚC khi merge code.
2. **Truy vết được:** Mọi khẳng định kỹ thuật phải kèm `file.py:DÒNG`.
3. **Tự động kiểm:** Script `gen-inventory.py` phát hiện số liệu lạc hậu.
4. **Một nhánh:** Tài liệu và code cùng nằm trong một PR.

---

## 2. Quy trình đồng bộ

### 2.1 Khi sửa code

```
1. Xác định tài liệu bị ảnh hưởng
2. Cập nhật tài liệu (trích dẫn file:line mới)
3. Chạy gen-inventory.py --check
4. Chạy test suite
5. Commit tài liệu + code cùng nhánh
```

### 2.2 Khi sửa tài liệu

```
1. Xác định code liên quan
2. Kiểm tra code có khớp tài liệu không
3. Nếu không: sửa code HOẶC sửa tài liệu
4. Chạy test suite
5. Commit
```

---

## 3. Script tự động

### 3.1 `gen-inventory.py`

Sinh báo cáo số liệu từ codebase:

```bash
.venv/Scripts/python.exe docs/system-design/_meta/tools/gen-inventory.py
```

Output: `docs/system-design/_meta/inventory.json`

### 3.2 Kiểm tra đồng bộ

```bash
.venv/Scripts/python.exe docs/system-design/_meta/tools/gen-inventory.py --check
```

Exit 0 = đồng bộ. Exit 1 = có lệch.

---

## 4. Xử lý lệch

| Loại lệch | Cách xử lý |
|:--|:--|
| Số liệu định lượng sai | Chạy `gen-inventory.py` để cập nhật |
| Khẳng định kỹ thuật sai | Sửa tài liệu, trích dẫn `file:line` mới |
| Code không khớp tài liệu | Sửa code hoặc sửa tài liệu (tùy trường hợp) |
| Tài liệu thiếu | Bổ sung tài liệu theo template |
