## 3. Common Issues

### 3.1 Rate Limit

**Symptom:** `ConnectionError: 429 Too Many Requests`

**Fix:**
```bash
# Tăng rate limit
export vnbroker_RATE_LIMIT_RPM=500
```

### 3.2 Auth Failed

**Symptom:** `ValueError: DNSE cần api_key và api_secret`

**Fix:**
```bash
# Set env vars
export DNSE_API_KEY=your_key
export DNSE_API_SECRET=your_secret
```

### 3.3 Empty DataFrame

**Symptom:** `history()` returns empty DataFrame

**Fix:**
```python
# Kiểm tra symbol có tồn tại không
from vnbroker.common.data import Listing
listing = Listing(source="KBS", show_log=False)
symbols = listing.all_symbols()
print("ACB" in symbols["symbol"].values)
```
