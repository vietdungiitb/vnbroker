## 1. Tổng quan

Kiến trúc bảo mật của vnbroker.

## 2. Credential Management

| Nguyên tắc | Mô tả |
|:--|:--|
| Zero-knowledge | Credentials không bao giờ rời client process |
| No logging | Không log API keys, OTPs, tokens, secrets |
| Redaction | Redaction trong logs cho sensitive fields |
| Direct connections | Không có intermediary gateway |

## 3. Auth Providers

| Provider | Auth Type | Storage |
|:--|:--|:--|
| DNSE | HMAC-SHA256 | Env vars |
| SSI | RSA + ConsumerID | Env vars |
| TCBS | OTP + API Key | Env vars |

## 4. Data Protection

| Data | Protection |
|:--|:--|
| API keys | Env vars, không hardcode |
| OTP | Không lưu, chỉ dùng 1 lần |
| Tokens | In-memory only |
| Logs | Redaction sensitive fields |

## 5. Rate Limiting

| Provider | Limit | Enforcement |
|:--|:--|:--|
| VCI | ~300 RPM | Token bucket |
| KBS | ~300 RPM | Token bucket |
| DNSE | Provider limit | Client-side |
| SSI | 10 RPS | Client-side |
