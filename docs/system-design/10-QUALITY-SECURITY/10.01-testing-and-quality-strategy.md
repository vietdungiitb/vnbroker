## 1. Tổng quan

Chiến lược testing và quality assurance.

## 2. Test Levels

| Level | Scope | Tool |
|:--|:--|:--|
| Unit | Single function/class | pytest |
| Contract | Provider schema | pytest |
| Integration | Live API | pytest (gated) |
| Performance | Benchmark | manual |

## 3. Test Organization

```
tests/
├── unit/              # Unit tests (mock-based)
│   ├── core/
│   ├── common/
│   ├── explorer/
│   └── api/
├── contract/          # Contract tests (schema)
├── integration/       # Live API tests (gated)
└── examples/          # Examples & benchmarks
```

## 4. Quality Gates

| Gate | Command | Exit |
|:--|:--|:--|
| Unit tests | `pytest tests/unit -q` | 0 |
| Contract tests | `pytest tests/contract -q` | 0 |
| Lint | `ruff check vnbroker` | 0 |
| Type check | `mypy vnbroker --strict` | 0 |

## 5. Coverage

| Module | Coverage |
|:--|:--:|
| `vnbroker/core/` | ~80% |
| `vnbroker/common/` | ~70% |
| `vnbroker/explorer/` | ~60% |
| `vnbroker/api/` | ~75% |
