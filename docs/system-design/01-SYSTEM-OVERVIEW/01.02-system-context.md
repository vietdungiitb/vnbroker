## 1. Tổng quan

vnbroker là thư viện Python độc lập, không có backend server. Nó cung cấp API cho
ứng dụng bên ngoài (như VnInvestSite) để truy xuất dữ liệu thị trường chứng khoán.

## 2. Sơ đồ bối cảnh

```
┌─────────────────────────────────────────────────────────────┐
│                    ỨNG DỤNG BÊN NGOÀI                       │
│              (VnInvestSite, Bot, Dashboard)                 │
└─────────────────────────┬───────────────────────────────────┘
                          │ Python API
                          ▼
┌─────────────────────────────────────────────────────────────┐
│                      VNBROKER                               │
│  ┌─────────────┐  ┌──────────────┐  ┌───────────────────┐  │
│  │ Bulk Router │→ │ Health Router│→ │ Provider Pool     │  │
│  └─────────────┘  └──────────────┘  └───────────────────┘  │
│         │                                    │              │
│         ▼                                    ▼              │
│  ┌─────────────┐                    ┌───────────────────┐  │
│  │ Normalizer  │                    │ Connection Pool   │  │
│  └─────────────┘                    └───────────────────┘  │
└─────────────────────────┬───────────────────────────────────┘
                          │ HTTP/HTTPS
        ┌─────────────────┼─────────────────┐
        ▼                 ▼                 ▼
   ┌─────────┐      ┌─────────┐      ┌─────────┐
   │   VCI   │      │   KBS   │      │  DNSE   │
   │(no-auth)│      │(no-auth)│      │(HMAC)   │
   └─────────┘      └─────────┘      └─────────┘
```

## 3. Actors

| Actor | Mô tả | Tương tác |
|:--|:--|:--|
| **Người dùng cuối** | Nhà đầu tư, analyst | Xem giá, phân tích, quản lý danh mục |
| **Ứng dụng** | VnInvestSite, Bot | Gọi API vnbroker để lấy dữ liệu |
| **Provider** | VCI, KBS, TCBS, DNSE, SSI | Cung cấp dữ liệu thị trường |

## 4. Dependencies bên ngoài

| Dependency | Mô tả |
|:--|:--|
| **VCI** | Viet Capital Securities — API công khai |
| **KBS** | KIS Vietnam Securities — API công khai |
| **TCBS** | Techcombank Securities — OpenAPI + OTP |
| **DNSE** | Định Nghĩa Securities — HMAC auth |
| **SSI** | SSI Securities — RSA + ConsumerID |
| **RSS** | CafeF, VnEconomy — tin tức |
| **FMARKET** | Quỹ mở — dữ liệu quỹ |

## 5. Ràng buộc

| Ràng buộc | Mô tả |
|:--|:--|
| **Rate-limit** | Mỗi provider có giới hạn request/giây |
| **Auth** | Một số provider cần API key/secret |
| **Schema** | Mỗi provider trả về schema khác nhau |
| **Timezone** | Dữ liệu phải tz-aware Asia/Ho_Chi_Minh |
