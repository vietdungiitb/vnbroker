## §1. Hệ thống này là gì

**vnbroker** là thư viện Python tích hợp dữ liệu thị trường chứng khoán Việt Nam.
Nó cung cấp API thống nhất cho dữ liệu giá, hồ sơ doanh nghiệp, tài chính, tin tức,
và giao dịch chứng khoán từ nhiều provider (VCI, KBS, TCBS, DNSE, SSI).

## §3. Kiến trúc hai tầng

### Tier 1 — Dữ liệu ẩn danh

Người dùng không cần biết provider. Hệ thống tự chọn provider ổn định và tự xoay vòng
khi gặp rate-limit / mất kết nối.

| Module | Providers | Auth |
|:--|:--|:--|
| quote | VCI, KBS | None |
| company | VCI, KBS | None |
| financial | VCI, KBS | None |
| listing | KBS, VCI | None |
| trading | KBS, VCI | None |
| news | VCI, KBS, RSS | None |

### Tier 2 — Dữ liệu cá nhân hóa

Người dùng chọn provider tường minh, mỗi broker giữ OpenAPI shape riêng.

| Broker | Auth | Features |
|:--|:--|:--|
| TCBS | OTP + API Key | Account, Money, Equity, Portfolio |
| SSI | RSA + ConsumerID | Account, Money, Equity, Market |
