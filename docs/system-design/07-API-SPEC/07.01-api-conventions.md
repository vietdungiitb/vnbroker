## 1. Tổng quan

Quy ước API trong vnbroker.

## 2. Naming Conventions

| Loại | Quy ước | Ví dụ |
|:--|:--|:--|
| Class | PascalCase | `Quote`, `Company`, `Finance` |
| Method | snake_case | `history()`, `intraday()`, `price_depth()` |
| Function | snake_case | `build_source_order()`, `record_success()` |
| Constant | UPPER_SNAKE | `OPEN_SOURCE_CANDIDATES`, `AUTO_SOURCE` |
| Private | `_leading_underscore` | `_auto_sources`, `_provider` |

## 3. Method Signatures

### 3.1 Quote

```python
def history(
    self,
    symbol: Optional[str] = None,
    start: Optional[str] = None,
    end: Optional[str] = None,
    interval: str = "1D",
    **kwargs
) -> pd.DataFrame: ...

def intraday(
    self,
    symbol: Optional[str] = None,
    **kwargs
) -> pd.DataFrame: ...

def price_depth(
    self,
    symbol: Optional[str] = None,
    **kwargs
) -> pd.DataFrame: ...
```

### 3.2 BulkAPI

```python
def history(
    self,
    symbols: List[str],
    start: Optional[str] = None,
    end: Optional[str] = None,
    interval: str = "1D"
) -> pd.DataFrame: ...

def price_board(
    self,
    symbols: Optional[List[str]] = None
) -> pd.DataFrame: ...
```

## 4. Return Types

| Method | Return Type | Mô tả |
|:--|:--|:--|
| `history()` | `pd.DataFrame` | OHLCV data |
| `intraday()` | `pd.DataFrame` | Intraday data |
| `price_depth()` | `pd.DataFrame` | Order book depth |
| `bulk.history()` | `pd.DataFrame` | Multi-symbol OHLCV |
| `bulk.price_board()` | `pd.DataFrame` | Multi-symbol price board |

## 5. Error Handling

| Error | Khi nào | Xử lý |
|:--|:--|:--|
| `ConnectionError` | Mất kết nối | Failover sang provider khác |
| `TimeoutError` | Request timeout | Retry + failover |
| `ValueError` | Thiếu tham số bắt buộc | Ném lỗi rõ ràng |
| `NotImplementedError` | Provider không hỗ trợ | Failover sang provider khác |

## 6. Metadata

Mọi DataFrame trả về có `attrs`:

```python
df.attrs["source"] = "KBS"
df.attrs["source_used"] = "KBS"
df.attrs["symbol"] = "ACB"
df.attrs["interval"] = "1D"
df.attrs["start"] = "2024-01-01"
df.attrs["end"] = "2024-06-30"
```
