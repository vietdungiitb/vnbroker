## 1. Tổng quan

Ma trận xác thực cho từng provider.

## 2. Tier 1 — Dữ liệu ẩn danh

| Provider | Auth | Env Vars | Required |
|:--|:--|:--|:--|
| VCI | None | — | No |
| KBS | None | — | No |
| DNSE | HMAC | `DNSE_API_KEY`, `DNSE_API_SECRET` | Yes |
| SSI | RSA | `VNBROKER_BROKER_SSI_API_KEY`, `VNBROKER_BROKER_SSI_API_SECRET` | Yes |
| TCBS | OTP | `TCBS_API_KEY`, `TCBS_API_SECRET` | Yes |

## 3. Tier 2 — Dữ liệu cá nhân hóa

| Broker | Auth | Env Vars | Required |
|:--|:--|:--|:--|
| TCBS | OTP + API Key | `VNBROKER_BROKER_TCBS_API_KEY` | Yes |
| SSI | RSA + ConsumerID | `VNBROKER_BROKER_SSI_API_KEY`, `VNBROKER_BROKER_SSI_API_SECRET` | Yes |

## 4. Auto-Detection

ProviderPool tự động detect auth providers từ env:

```python
# .env
DNSE_API_KEY=your_key
DNSE_API_SECRET=your_secret
# → DNSE tự động tham gia pool
```
