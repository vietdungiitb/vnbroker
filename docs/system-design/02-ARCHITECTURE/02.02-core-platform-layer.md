## 1. Tổng quan

Lớp nền tảng cung cấp các dịch vụ dùng chung cho toàn bộ hệ thống:

- **Provider Registry:** Đăng ký và khởi tạo providers
- **Source Router:** Định tuyến nguồn dữ liệu
- **Health Store:** Lưu trữ trạng thái sức khoẻ
- **Connection Pool:** Quản lý kết nối HTTP
- **Cache:** Bộ nhớ đệm TTL

## 2. Provider Registry

**File:** `vnbroker/core/registry.py`

```python
class ProviderRegistry:
    _registry: Dict[Tuple[str, str], Type] = {}
    
    @classmethod
    def register(cls, provider_type: str, source_name: str, provider_class: Type):
        cls._registry[(provider_type, source_name.lower())] = provider_class
    
    @classmethod
    def get(cls, provider_type: str, source_name: str) -> Type:
        return cls._registry[(provider_type, source_name.lower())]
```

**Đánh giá:**
- ✅ Đăng ký provider bằng decorator
- ✅ Tra cứu provider theo (type, source)
- ✅ Không có circular import

## 5. Connection Pool

**File:** `vnbroker/core/utils/connection_pool.py`

```python
class ConnectionPool:
    _instance: Optional["ConnectionPool"] = None
    _lock: threading.Lock = threading.Lock()
    
    @classmethod
    def get_instance(cls) -> "ConnectionPool":
        if cls._instance is None:
            with cls._lock:
                if cls._instance is None:
                    cls._instance = cls()
        return cls._instance
```

**Đánh giá:**
- ✅ Singleton pattern với double-checked locking
- ✅ Thread-safe (requests.Session)
- ✅ `HTTPAdapter(pool_connections=256, pool_maxsize=256)`
