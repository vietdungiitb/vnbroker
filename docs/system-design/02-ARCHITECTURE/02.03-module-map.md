## 1. Tổng quan

vnbroker được tổ chức thành các module độc lập, mỗi module chịu trách nhiệm một phạm vi rõ ràng.

## 2. Sơ đồ module

```
vnbroker/
├── __init__.py              # Entry point, lazy imports
├── base.py                  # BaseAdapter, dynamic_method
├── config.py                # Config, VERSION_REQUIREMENTS
├── constants.py             # Market constants
│
├── common/                  # Data layer
│   ├── data.py              # BaseComponent, Quote, Company, Finance, ...
│   ├── client.py            # Vnbroker class
│   ├── retail.py            # Retail facade
│   └── stream.py            # Stream facade
│
├── core/                    # Core infrastructure
│   ├── registry.py          # ProviderRegistry
│   ├── source_router.py     # AUTO source, health-based failover
│   ├── health_store.py      # HealthStore (SQLite + memory)
│   ├── bulk_router.py       # BulkRouter (multi-provider)
│   ├── health_router.py     # HealthRouter (real-time health)
│   ├── provider_pool.py     # ProviderPool (auth detection)
│   ├── unified_registry.py  # UnifiedRegistry
│   ├── adaptive_controller.py # AdaptiveController, GlobalPressure
│   └── utils/               # Utilities
│       ├── client.py        # HTTP client, ProxyConfig
│       ├── connection_pool.py # ConnectionPool singleton
│       ├── normalizer.py    # Normalizer
│       ├── cache.py         # TTLCache
│       ├── parser.py        # Data parsing
│       ├── transform.py     # Data transformation
│       └── ...
│
├── explorer/                # Market data providers (Tier 1)
│   ├── vci/                 # Viet Capital Securities
│   ├── kbs/                 # KIS Vietnam Securities
│   ├── tcbs/                # Techcombank Securities
│   ├── dnse/                # Định Nghĩa Securities
│   ├── ssi/                 # SSI Securities
│   ├── rss_cafef/           # RSS news
│   ├── rss_vneconomy/       # RSS news
│   └── fmarket/             # Fund data
│
├── broker/                  # Brokerage (Tier 2)
│   ├── tcbs/                # TCBS iFlash OpenAPI
│   ├── ssi/                 # SSI FastConnect
│   ├── base.py              # BaseBrokerClient
│   ├── registry.py          # BrokerRegistry
│   └── session.py           # BrokerSession
│
├── brokerage/               # Brokerage (Private API)
│   ├── tcbs/                # TCBS Private API
│   └── base.py              # BrokerageBase
│
├── connector/               # Low-level connectors
│   ├── dnse/                # DNSE HMAC + JWT
│   └── binance/             # Binance
│
├── api/                     # Unified API
│   ├── quote.py             # Quote adapter
│   ├── company.py           # Company adapter
│   ├── financial.py         # Finance adapter
│   ├── listing.py           # Listing adapter
│   ├── news.py              # News adapter
│   ├── trading.py           # Trading adapter
│   ├── snapshot.py          # MarketSnapshot
│   ├── stream.py            # Stream adapter
│   └── bulk.py              # BulkAPI
│
├── ui/                      # Unified UI
│   ├── market.py            # Market facade
│   ├── reference.py         # Reference facade
│   ├── fundamental.py       # Fundamental facade
│   ├── retail.py            # Retail facade
│   └── registry.py          # show_api, show_doc
│
├── news/                    # News processing
│   ├── normalize.py
│   ├── dedup.py
│   └── filtering.py
│
├── bot/                     # Notifications
│   └── notify.py
│
└── analytics/               # Technical indicators
    └── indicators.py
```

## 3. Module dependencies

```
api/* → common/data.py → core/* → explorer/*
ui/* → common/data.py → core/*
broker/* → connector/*
```
