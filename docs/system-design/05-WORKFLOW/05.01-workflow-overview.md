## 1. Tổng quan

## 2. Luồng bulk history

```
User: Market(auto=True).bulk.history(symbols=["ACB","VNM"], start="2024-01-01")
    │
    ▼
BulkAPI.history()
    │
    ├──→ ProviderPool.get_available_providers("quote")
    │         └──→ ["vci", "kbs"]
    │
    ├──→ BulkRouter.fetch_history(symbols, start, end)
    │         │
    │         ├──→ HealthRouter.get_healthy_providers("quote")
    │         │         └──→ ["vci", "kbs"]
    │         │
    │         ├──→ Distribute: vci=["ACB"], kbs=["VNM"]
    │         │
    │         ├──→ ThreadPoolExecutor
    │         │         ├──→ VCI.fetch_multiple(["ACB"])
    │         │         └──→ KBS.fetch_multiple(["VNM"])
    │         │
    │         └──→ Merge results
    │
    ▼
Normalizer.normalize_history(result, start, end)
    │
    ▼
DataFrame (tz-aware, sorted, with symbol column)
```

## 3. Luồng failover

```
Provider A (VCI)
    │
    ├──→ Request → Success → record_success()
    │
    ├──→ Request → 429 Error → record_failure()
    │         └──→ Health store: failures=1, cooldown=5s
    │
    ├──→ Request → 429 Error → record_failure()
    │         └──→ Health store: failures=2, cooldown=10s
    │
    ▼
Provider B (KBS) ← failover
    │
    └──→ Request → Success → record_success()
```

## 4. Luồng auth provider

```
User sets env: DNSE_API_KEY=*** DNSE_API_SECRET=***

ProviderPool.__init__()

    ├──→ _detect_auth_providers()
    │         └──→ DNSE detected
    │
    ▼
ProviderPool.get_available_providers("quote")
    │
    └──→ ["vci", "kbs", "dnse"]
```
