## 1. Tổng quan

vnbroker là thư viện Python, không cần triển khai server. Người dùng cài đặt và import.

## 2. Cài đặt

```bash
pip install vnbroker
# hoặc
pip install -e .
```

## 3. Environment Variables

| Variable | Purpose | Required |
|:--|:--|:--|
| `DNSE_API_KEY` | DNSE HMAC Key | DNSE only |
| `DNSE_API_SECRET` | DNSE HMAC Secret | DNSE only |
| `VNBROKER_BROKER_SSI_API_KEY` | SSI API Key | SSI only |
| `VNBROKER_BROKER_SSI_API_SECRET` | SSI API Secret | SSI only |
| `VNBROKER_BROKER_TCBS_API_KEY` | TCBS API Key | TCBS only |
| `vnbroker_RATE_LIMIT_RPM` | Rate limit | No |
| `vnbroker_LISTING_CACHE_TTL` | Listing cache TTL | No |

## 4. Health Check

```python
from vnbroker.core.source_router import get_source_health_snapshot

health = get_source_health_snapshot("quote")
# {"VCI": {"failures": 0, "in_cooldown": False, ...}}
```

## 5. Monitoring

- Health store: SQLite + in-memory
- Logs: Python logging
- Metrics: `get_source_health_snapshot()`
