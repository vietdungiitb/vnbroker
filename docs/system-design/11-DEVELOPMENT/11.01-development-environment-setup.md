## 1. Tổng quan

Hướng dẫn cài đặt môi trường phát triển.

## 2. Prerequisites

| Requirement | Version |
|:--|:--|
| Python | 3.10+ |
| pip | Latest |
| uv | Optional |

## 3. Setup

```bash
# Clone repo
git clone https://github.com/vietdungiitb/vnbroker.git
cd vnbroker

# Create venv
python -m venv .venv
source .venv/bin/activate  # Linux/Mac
# .venv\Scripts\activate   # Windows

# Install dependencies
pip install -e .[test,lint]
```

## 4. Environment Variables

```bash
# .env
DNSE_API_KEY=your_key
DNSE_API_SECRET=your_secret
VNBROKER_BROKER_SSI_API_KEY=your_key
VNBROKER_BROKER_SSI_API_SECRET=your_secret
```

## 5. Verify

```bash
pytest tests/unit tests/contract -q

```
