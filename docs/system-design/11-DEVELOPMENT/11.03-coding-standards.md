## 1. Tổng quan

Chuẩn code áp dụng cho vnbroker.

## 2. Style

| Rule | Convention |
|:--|:--|
| Functions | snake_case |
| Classes | PascalCase |
| Constants | UPPER_SNAKE |
| Private | `_leading_underscore` |
| Type hints | Bắt buộc (mypy strict) |
| Docstrings | Google style |

## 3. Immutability

- Prefer dataclasses/frozen
- Spread over mutation
- Copy DataFrame trước khi modify

## 4. File Size

| Type | Max Lines |
|:--|:--:|
| Typical | 200-400 |
| Max | 800 |

## 5. Testing

| Rule | Convention |
|:--|:--|
| TDD | RED → GREEN → REFACTOR |
| Unit tests | Mock-based |
| Contract tests | Schema validation |
| Integration | Live API (gated) |

## 6. Security

| Rule | Convention |
|:--|:--|
| No secrets | Không hardcode API keys |
| No logging | Không log sensitive fields |
| Redaction | Redact trong logs |
| dry_run | Default True cho write operations |
