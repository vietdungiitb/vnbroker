## 1. Tổng quan

Quy trình phát triển phần mềm (SDLC) áp dụng cho vnbroker.

## 2. Workflow

```
1. Plan → docs/PLAN_<TASK>.md
2. Audit Plan → docs/PLAN_AUDIT.md (GATE 1)
3. Claim → docs/CLAIMS.md (GATE 2)
4. Code → delegate_task (GATE 3)
5. Audit Code → docs/AUDIT_<TASK>.md (GATE 4)
6. Test → docs/TEST_REPORT.md (GATE 5)
7. Close → docs/REPORT_FINAL.md (GATE 6)
8. Retrospective → Hazard registry
```

## 3. Gates

| Gate | Condition | Command |
|:--|:--|:--|
| G1 | Plan Audit PASS | `grep "PASS" docs/PLAN_AUDIT.md` |
| G2 | Claims no overlap | `node check-overlap.cjs --file docs/CLAIMS.md` |
| G3 | Code changed | `git diff HEAD --name-only` |
| G4 | Audit 0 errors | `grep "PASS" docs/AUDIT_<TASK>.md` |
| G5 | Tests pass | `pytest tests/unit tests/contract -q` |
| G6 | Report complete | `grep "COMPLETED" docs/REPORT_FINAL.md` |
